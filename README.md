# Trustworthy Autonomy Lab website

Organization homepage and publication directory for the Trustworthy Autonomy Lab at Washington University in St. Louis.

Planned live URL: <https://trustworthyautonomy.github.io/>

## Publishing

1. Create a public repository in the `TrustworthyAutonomy` organization named exactly `TrustworthyAutonomy.github.io`.
2. Push this directory to its `main` branch.
3. In **Settings → Pages**, select **GitHub Actions** as the source.
4. Add `https://trustworthyautonomy.github.io/sitemap.xml` to Google Search Console after deployment.

The site links to each paper page with the full paper title as anchor text. Each paper page links back to this publication directory.
